## 0. 一页读懂

**做什么**:一套 5 原语的数组 API,wasm/js 走纯 MoonBit 标量,native 走 C 标量,RISC-V 走 RVV;同一份公开签名,按目标选实现。

**交付物**:可用 `moon add` 引入的包 + 可复现的 5×3×3 基准表 + 交叉编译到 RV64 的脚本与配方。

**成功标准**:

1. 干净目录 `moon add aurasuisui/rvv@0.1.0` 后,wasm-gc 与 native 都跑出正确结果。
2. 交叉编译到 RV64 的产物在 qemu 上走 RVV 分支,结果与标量逐元素相等。
3. 5 个原语的基准表可一条命令复现,数字标口径。
4. README 里的交叉编译配方可被第三方照着复现第 2 条。

**周期**:16 个工作日(建议 11/14 起,12/05 发布,含 3 天缓冲)。

## 三、范围

### 3.1 API(5 个原语)

| API | 语义 | 边界 |
|---|---|---|
| `sum(xs) -> Int64` | 求和,中间值 Int64 | 空数组返回 0 |
| `count_ge(xs, thr) -> Int` | 统计 >= thr 的元素数 | 空数组返回 0 |
| `prefix_sum(xs) -> Unit` | 原地前缀和,按 32 位回绕 | 空数组无操作 |
| `filter(xs, thr) -> FixedArray[Int]` | 取出 >= thr 的元素,保持原序 | 无匹配返回空数组 |
| `dot(a, b) -> Int64` | 点积,中间值 Int64 | 长度不等 panic(`rvv: dot length mismatch`) |

### 3.2 三层实现

| 层 | 文件 | 何时生效 |
|---|---|---|
| MoonBit 标量 | `src/scalar/impl.mbt` | wasm / wasm-gc / js |
| C(标量 + RVV) | `src/native/kernel.c`(`native-stub`) | native |
| 分派 | `src/lib.mbt` + 两个 target 文件 | 全后端,只做参数检查与转发 |

`kernel.c` 用编译期开关,不做运行时探测:

```c
#include <moonbit.h>
#if defined(__riscv_vector)
#include <riscv_vector.h>
#define RVV 1
#endif
```

### 3.3 源码结构(不堆平)

```
src/
├── moon.pkg                # 公开包 aurasuisui/rvv;native-stub + 文件级 targets

├── dispatch_wasm.mbt       # targets: wasm, wasm-gc, js → 标量
├── dispatch_native.mbt     # targets: native → extern "C"
├── scalar/                 # M1 起:纯 MoonBit 标量实现(可无条件导入)
│   ├── moon.pkg
│   └── impl.mbt
├── native/
│   └── kernel.c            # 只是 C 文件,由 native-stub 引用(不是包)
├── tests/                  # M1 起:黑盒测试
│   ├── moon.pkg
│   └── api_test.mbt
└── probe/                  # M0 可执行探针(M4 决定保留为 example 或删除)
    ├── moon.pkg
    └── main.mbt
scripts/
├── cross-riscv.sh          # cc/ar wrapper + 交叉编译
├── run-qemu.sh
└── bench.sh
bench/                      # 裸机 C harness(无 moon.pkg,不参与包构建)
.github/workflows/ci.yml    # 仅 wasm/native 主机门禁
```

**结构结论(M0 已采用回退)**:`for "native"` 条件包导入在本工具链不被支持(解析错误);给 native 子包加 `supported_targets` 后,wasm-gc 构建会报依赖图不兼容。因此 v0.1.0 用**单包 + 文件级 `targets`**(F13 模式):`kernel.c` 放 `src/native/` 由 `native-stub` 引用;纯标量实现与黑盒测试在 M1 以可无条件导入的子包加入(`src/scalar/`、`src/tests/`)。
